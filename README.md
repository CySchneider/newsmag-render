# newsmag-render

Render- und Abruf-Jobs für [newsmag.ch](https://newsmag.ch) (Story-Video, Reels/YouTube, Karussell, Sportdaten: Fussball über API-Sports, Eishockey vom Verband SIHF).
Die Workflows werden ausschliesslich vom Newsmag-Worker gestartet und holen ihre Aufträge mit einem Einmal-Token.
Keine Schlüssel im Code. Musik und Inhalte werden pro Lauf vom Worker geladen.
